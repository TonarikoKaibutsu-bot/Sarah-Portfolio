# Sarah Portfolio MVP

A simple static portfolio starter for an Implementation & Laboratory Operations professional.

## What this is
This is a first-pass MVP site designed to show:
- Implementation thinking
- Laboratory operations expertise
- Quality systems mindset
- Process improvement and adoption work
- Case-study storytelling

## Files
- `index.html` — one-page portfolio
- `css/style.css` — dark professional styling
- `js/main.js` — small reveal animation
- `case-studies/` — draft Markdown case studies
- `assets/` — put your resume PDF here

## How to use with GitHub Pages
1. Create a GitHub repository, for example `sarah-portfolio`.
2. Upload these files to the repository root.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save. GitHub will publish the site.

## What to customize
- Replace `Sarah` with your preferred public name.
- Replace contact placeholders.
- Add a real resume PDF to `assets/`.
- Anonymize all company-specific details.
- Add screenshots or diagrams only if they contain no confidential information.

## Portfolio principle
This site should prove how you think, not just where you have worked.
